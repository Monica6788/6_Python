5. STEP 6 - 담당자의 "정확도 84%" 질문에 대한 원인 설명
    1) DummyClassifier와 RandomForest의 정확도가 거의 같은 이유
      : 일반적으로 연체자보다는 제시간에 반납하는 이용자가 압도적으로 많다. 즉 현재 모집단의 데이터는 매우 불균형하다. 따라서 수적으로 압도적인 우세를 보이는 클래스는 N(음성, 즉 연체자가 아닌 정상 이용자 클래스)인데, DummyClassifier는 무조건 우세 클래스로 찍기 때문에 정확도 자체는 높을 수 있다.
    2) 담당자가 말한 "정확도 84%인데 연체를 못 잡는다"의 의미
      : 정확도가 높더라도 이는 우세한 클래스(N)로 무작정 찍은 것이므로 재현율(실제 P, 즉 연체자를 걸러내는 비율)이 0에 수렴한다. 따라서 정확도만 보고 모델의 성능을 판단해서는 안 된다.
    3) class_weight="balanced"를 넣으면 정확도가 떨어지는데, 그럼에도 이 옵션을 써야 하는 이유
      : 소수 클래스에 가중치를 주어 실제 상황을 더 잘 재현하도록 해야 실질적으로 쓸모있는 모델을 만들 수 있기 때문이다.

6. STEP 7 - 이 문제에서 FN 과 FP 의 의미와 리스크
     - TP: 연체자를 연체자로 판단 (정답)
     - FN: 연체자를 정상 이용자로 판단 (오답)
     - FP: 정상 이용자를 연체자로 판단 (오답)
     - TN: 정상 이용자를 정상 이용자로 판단 (정답)

     **FN보다 FP가 더 치명적이다.**
     연체자가 아닌데 연체자로 취급하여 비용을 청구하거나 경고 알림 등을 보낸다면 이용자 입장에서 불쾌감을 느낄 수 있고, 이는 이용자의 이탈로 이어질 수 있기 때문이다.
     (스팸 메일이 아닌데 스팸 메일로 처리하면 중요한 메일을 못 받게 될 수 있는 것과 같다고 판단)
     청구 알림만 보내고 끝났다면 단순 CS 비용으로 처리할 수 있겠지만, 만에 하나 자동 결제 시스템이 존재하여 정상 이용자에게서 자동으로 연체료를 출금하게 되면 법적 문제로까지 이어질 수 있고, 기업 이미지에도 큰 손상을 입힐 수 있다.

7. STEP 8 - **비용 기반 임계값 선택 근거와 비용 절감 효과**
    임계값 0.05일 때 4,316,000원으로 총비용이 가장 작고, 절감액이 2,884,000원으로 가장 크다.
    **절감액 계산 로직**
    : 아무 예측도 하지 않고 전부 정상 이용자로 간주한다면 P의 개수는 모두 0이 된다.
      => TP = FP = 0
      y_test에서 1(양성)의 개수가 연체자 수인데, 아무 예측도 하지 않으므로 전부 FN이 된다.
      (y_test는 1차원 배열이나 Series이므로 len 대신 sum 사용)
      => FN = sum(y_test == 1)
      FP = 0과 FN = sum(y_test == 1)을 총비용 공식에 대입하여 전부 N으로 찍을 때의 총비용을 알 수 있고, 여기서 임계값에 따라 예측할 때의 총비용을 빼면 절감액을 구할 수 있다.
      => saving = sum(y_test == 1) * 15_000 - total_cost
